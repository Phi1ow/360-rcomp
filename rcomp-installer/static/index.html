Check a game

Pick one of your Xbox 360 disc images. R-comp's real tools read the disc and recompile its code, then the report says what works, what is missing and whether the game can be tried on the PS5 now. A work order for adding the missing support is written next to the report.

All games

Test as many games as you like: every check and every PS5 result is stored, then gathered into one backlog that ranks the missing functions (first those a game really called on the PS5, then those the most games need). "Export for the AI" downloads that whole list as one self-contained file to hand over in one go.

Install a finished app folder

Uploads the folder to /data/homebrew/<id> over FTP, reads every file back (SHA-256), sets mode 0777 with the chmod payload, adds the folder to ShadowMount+'s manual.lst (after a backup) and waits until manual.status and /system_ex/app/<id> confirm it.

Package recompiled artifacts into an app folder

Reads the title id, name and image from the decoded XEX, then assembles eboot.bin, sce_sys/param.json, sce_sys/icon0.png (512×512), sce_module/libc.prx, image/plain.xex, game/ and manifest.sha256.

Recompile from the disc → app folder

Drives the real R-comp pipeline: extract-xiso → m6_inventory.py (XenonAnalyse + XenonRecomp) → build_ps5_archives.sh (AOT C++) → build-radv-probes.sh game (pinned RADV link, fake SELF) → app folder. Tens of minutes to hours. Titles R-comp does not support yet stop with BLOCKED or FAIL and the real logs.
